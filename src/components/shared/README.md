# Shared state components

Use these for every loading, empty, error, success, and confirmation state so features behave the same way.

| Component                                        | Use it when                                                       | Notes                                                                                                                                                                                                                                                                         |
| ------------------------------------------------ | ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TableSkeleton`, `CardSkeleton`, `ChartSkeleton` | A list, a set of cards, or a chart is loading                     | One polite `role="status"` per area with a spoken `label`; the blocks are `aria-hidden`. Pass a specific label ("Loading customers").                                                                                                                                         |
| `EmptyState`                                     | A list or section has no records                                  | `title` says what is empty, `description` says why and what to do, `action` is the call to action that creates the first record.                                                                                                                                              |
| `ErrorAlert`                                     | A request failed and the page cannot continue                     | `role="alert"`, announced when it appears. Pass `error` (the API error envelope body) or `message`, plus `requestId`. Optional `onRetry`.                                                                                                                                     |
| `ToastProvider`, `notify`                        | A quick result of a user action                                   | Mounted once in `src/app/layout.tsx`. `notify.success("Changes saved")`: past tense, same words as the button. Polite live region; never moves focus.                                                                                                                         |
| `ConfirmDialog`                                  | Before a destructive or hard-to-undo action                       | `confirmLabel` is a verb ("Archive customer"). Focus starts on Cancel, Tab stays inside, Esc and Cancel close it, focus returns to the opener. While `onConfirm` runs, Esc is ignored and both buttons are disabled; if it throws, the dialog stays open and shows the error. |
| `StatePanel`, `PlannedPage`, `ErrorPanel`        | Full-page messages: not found, route error, feature not built yet | Built on the same layout.                                                                                                                                                                                                                                                     |

Motion is removed globally by the `prefers-reduced-motion` rule in `src/app/globals.css`. Tests: `src/components/shared/shared-states.test.tsx` (axe in both themes, focus trap, Esc, live regions).
