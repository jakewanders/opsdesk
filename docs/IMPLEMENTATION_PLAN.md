# Implementation plan

Maps every P0 and P1 feature in PRD section 2 (F01 to F17) to the files, migrations, and tests that deliver it, with the Linear issues that own the work. P2 features (F18 to F22) are milestone M6 and start only after P0 and P1 pass.

- **Source of truth:** the PRD in Linear (project "OpsDesk — Full-Stack Business Operations SaaS (v1)").
- **Traceability:** the Requirements Traceability Matrix document in the same project maps REQ-001 to REQ-108 to issues. Issues named `P-nn` are specified in the "Pending Issues" document because the Linear free issue limit stopped their creation; they are tracked in `docs/PROGRESS.md` by their key.
- **Status:** this file is a plan. It never records that something is done; real results live in `docs/PROGRESS.md`.
- **Naming:** paths follow the layout in PRD section 10. Migration names are planned, not created: files are `supabase/migrations/<timestamp>_<name>.sql`. Tests are Vitest unit/integration (`*.test.ts`), pgTAP (`supabase/tests/*.sql`), or Playwright (`e2e/*.spec.ts`).
